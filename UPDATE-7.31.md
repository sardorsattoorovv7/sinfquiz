# SinfQuiz 7.31

Fanlar 3D bog‘ning ikki tomonida joylashdi. Model avtomatik ochiladi. Ochish, yopish, yashirish va pauza tugmalari olib tashlandi. Kamera boshqaruvi va vaqt sozlamalari saqlandi.

Faqat ikkita ommaviy, versiyalangan GLB model CacheStorage va HTTP keshida saqlanadi. Shaxsiy ma’lumotlar va kirish javoblari keshlanmaydi. Brauzer keshini tozalash yoki brauzer tomonidan joy bo‘shatilishi keyingi yuklashni talab qiladi. Bu butun saytni internetsiz ishlatish degani emas.

Migratsiya kerak emas. Mavjud .env qiymatlarini saqlang; npm install va npm run dev. Vercel: npm run build, dist.
