# 7.13.2 — Audio labirint xatosini aniqlash

Audio labirint bosh sahifadan bevosita ochiladigan paketga kiritildi; ochish paytida alohida JavaScript modulini yuklashga bog‘liq emas. Bo‘lim manzili yangilanganda ham saqlanadi.

Umumiy xato oynasi endi asl JavaScript xabarini **Xato tafsilotini ko‘rsatish** bo‘limida chiqaradi. Agar muammo davom etsa, shu tafsilot xatoning aniq sababini topishga yordam beradi.

Supabase migratsiyasi kerak emas. O‘zgarishlar saytda ko‘rinishi uchun yangi deploy qiling.
