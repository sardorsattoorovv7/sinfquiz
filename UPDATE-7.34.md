# SinfQuiz 7.34 — Registon maydoni

Bosh sahifaga Global Digital Heritage and GDH-Afrika tayyorlagan haqiqiy Registon majmuasining 3D skani qo‘shildi. Ulug‘bek, Sherdor va Tillakori madrasalari, maydon va atrofdagi hudud modelda ko‘rinadi. Venetsiya tanlovi bekor qilindi; uning model fayllari bu relizga qo‘shilmagan.

Kompyuter GLB: 8 679 136 bayt. Telefon GLB: 6 011 624 bayt. Telefon versiyasida detallarni saqlash uchun kompyuterdagi geometriya darajasi qoldirildi; teksturalar 512px. Kompyuter teksturalari 1024px. Model LOD soddalashtirilgan, Meshopt bilan siqilgan; binolar qayta qo‘lda chizilmagan. Modelga yaqinlashish va aylantirish ishlaydi. Avtomatik aylanish, vaqtga mos yorug‘lik, kesh, reduced-motion va yashirin tabda renderingni to‘xtatish saqlandi.

## Ishga tushirish

Migratsiya kerak emas. Mavjud .env qiymatlarini saqlang. npm install; npm run dev. Vercel: npm run build, output dist. Brauzer modelni birinchi yuklashdan so‘ng keshga saqlaydi; brauzer uni tozalashi mumkin. Boshqa modullar va RLS o‘zgartirilmagan.
