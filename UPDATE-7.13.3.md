# 7.13.3 — Audio labirint xaritasi xatosi

Labirintdagi xarita belgisi lucide ikonka sifatida `Map` nomini ishlatib, JavaScript’ning `Map` konstruktorini bosib ketgan. O‘yin taxtasi chizilganda shu sabab `Map is not a constructor` xatosi chiqqan. Ikonka endi `MapIcon` deb nomlangan; JavaScript’ning `Map` obyekti eshiklar indeksini tuzishda ishlaydi.

Qo‘shilgan UI regression testi faol xaritani yuklaydi, “Boshlash”ni bosadi va labirint taxtasi chizilganini tekshiradi. Supabase migratsiyasi kerak emas.
