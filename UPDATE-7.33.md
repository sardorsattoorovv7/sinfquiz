# SinfQuiz 7.33 — keng shahar

City — Invictus.Art.00 tayyor 3D modeli o‘rnatildi. Binolar, ko‘chalar, avtomobillar, sport maydoni va daraxtlar muallif modelidan. Model avtomatik sekin aylanadi; fan tugmalari yuklanish va kamera holatlarida bir joyda qoladi. Model GLB hajmi 1 460 304 bayt; muallif geometriyasi saqlandi, teksturalar WebP, Meshopt siqish ishlatildi. Telefon varianti ham shu hajmda: dastlabki teksturalar allaqachon kichik.

Model haqiqiy GLB, fon rasmi emas. Manba: https://sketchfab.com/3d-models/city-deb4dc75e62346c19c117bf61334eeb5 . CC BY 4.0, muallif ko‘rsatilgan. Asl ko‘rinish stilizatsiyalangan shahar, fotorealistik shahar emas. Suv havzasi yoki ko‘prik asl modelda yo‘q; ular bor deb ko‘rsatilmaydi.

Kesh va qurilma yukini moslash saqlandi. Reduced motion tizim sozlamasi avtomatik aylanishni o‘chiradi. Migratsiya kerak emas. .env ni saqlang; npm install; npm run dev. Vercel: npm run build, dist.
