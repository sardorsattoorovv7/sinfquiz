# Tekshiruv

170 mavjud Node testi va 2 yangi kesh testi o‘tdi. Production build o‘tdi. Chromium orqali haqiqiy GLB, kamera, klaviatura, tungi rejim, mobil va desktop tekshirildi. Model HTTP so‘rovi bloklangan takroriy yuklashda ham CacheStorage orqali ochildi. 6 accessibility tekshiruvi, mehmon test kodi, autentifikatsiya darvozasi va umumiy sahifalar o‘tdi.

SwiftShader sinovida parallel shader extension ogohlantirishi mavjud. Navigatsiya sinovida yuklanish vaqtida sahnadan chiqilganda bekor qilingan blob teksturalari haqida log chiqadi; production model sinovi muvaffaqiyatli.
