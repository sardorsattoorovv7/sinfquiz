# Tekshiruv

172 Node testi muvaffaqiyatli. Mobil variant qayta tayyorlangach model va kesh bo‘yicha 4 maqsadli test qayta o‘tdi. Production build va Chromium haqiqiy Registon GLB, avtomatik aylanish, kamera, klaviatura, tungi rejim, 320–1440px ko‘rinishlar, yuklanishdagi fan joylashuvi va model keshini tekshirdi. 6 accessibility tekshiruvi, mehmon test kodi, autentifikatsiya darvozasi va no-JS umumiy sahifalar o‘tdi.

Sinov GPU o‘rniga SwiftShader ishlatadi; real telefonlarda FPS kafolati berilmaydi. Navigatsiyada tugallanmagan yuklash bekor qilinganda blob tekstura loglari chiqishi mumkin; modelning to‘liq yuklanish testi muvaffaqiyatli. Global Digital Heritage skani daraxtlarda va model chekkalarida fotogrammetriya artefaktlarini o‘z ichiga oladi; u fotorealistik qayta qurilgan CAD model emas.
