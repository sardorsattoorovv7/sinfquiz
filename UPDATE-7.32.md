# SinfQuiz 7.32

Tayyor Stylized Mini Floating Island (Tom Verbeeck, CC BY 4.0) modeli qo‘shildi. Manba va litsenziya model ostida va public/models/island/v7.32 ichida. Muallif geometriyasi saqlandi; teksturalar 1024/512px WebP, geometriya Meshopt bilan siqildi. Model 3.67 MB, telefon varianti 3.15 MB.

Model avtomatik sekin aylanadi. Qo‘lda aylantirish rejimida kamera foydalanuvchiga beriladi. Harakatni kamaytirish tizim sozlamasi yoqilsa avtomatik aylanish o‘chadi. Ekrandan tashqarida va yashirin tabda rendering to‘xtaydi. Pause/yashirish/ochish tugmalari qaytarilmadi.

Fan tugmalari yuklanish, xato va kamera boshqaruvi holatlarida bir xil joyda qoladi. Birinchi yuklashdan so‘ng ikkita ommaviy model brauzer keshida saqlanadi; brauzer uni tozalashi mumkin. Boshqa mavjud modullar va kirish tartibi saqlandi.

Migratsiya kerak emas. .env qiymatlarini saqlang. npm install; npm run dev. Vercel build: npm run build, output: dist.
